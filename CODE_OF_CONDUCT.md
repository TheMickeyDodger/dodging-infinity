# Code of Conduct

Dodging Infinity is an open technical project. Participation should make the project more rigorous, useful, and welcoming to people who want to contribute in good faith.

## Expected behavior

- Be respectful and constructive.
- Critique ideas, code, evidence, and architecture rather than people.
- Assume good faith while still demanding technical rigor.
- Give useful context when disagreeing or rejecting a proposal.
- Respect privacy, security boundaries, and confidential information.
- Make room for contributors with different backgrounds, tools, model preferences, and levels of experience.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate intimidation, doxxing, sustained disruption, or publishing another person's private information without permission are not acceptable.

## Technical disagreement

Strong disagreement is welcome. Dodging Infinity is explicitly built around adversarial review and challenge.

Keep that disagreement focused on claims that can be reasoned about, tested, reproduced, or supported with evidence.

## Enforcement

Project maintainers may edit or remove comments, close or lock discussions, reject contributions, or restrict participation when behavior materially undermines the project or its community.

Serious conduct concerns should be raised privately with the project maintainer rather than posted publicly.
