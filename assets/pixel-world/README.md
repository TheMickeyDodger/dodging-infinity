# World screenshots

Owner-supplied captures of the running Pixel Agents DI world, 16 October 2026. Used with the repository owner's permission.

The six images are crops normalized to standard 8-bit sRGB PNG of the supplied screenshots. Browser chrome and the local access token were removed; no world content was generated or composited. Embedded text and EXIF metadata were removed.

- `world-map.png`: complete living metropolis and live Mission inspector.
- `palace-and-forest.png`: palace office and surrounding forest.
- `office-life.png`: office rooms and decorative residents.
- `grand-offices-and-cathedral.png`: additional offices and cathedral quarter.
- `waterfront.png`: promenade, beach and ocean.
- `river-valley-farmland.png`: crops, barns and river crossings.

These document appearance and observations at capture time, not Mission success or live concurrency. Decorative residents and static animal/vehicle artwork do not represent agent work. Code and underlying asset notices remain in `integrations/pixel-agents/UPSTREAM.md` and `packaging/di/CREDITS.txt`.
